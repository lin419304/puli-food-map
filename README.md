🗺️ 埔里美食地圖 (Puli Food Map)

歡迎來到我的個人埔里美食地圖！

這是一個專門為了在埔里生活、求學的大家所打造的在地美食口袋名單網站。身為一個常常不知道「今天到底要吃什麼」的學生，我決定把自己真心吃過、毫無保留的真實美食心得整理成這個網站。

✨ 這個網頁是用來幹嘛的？

真實踩點分享：這裡沒有業配，只有我親自品嚐過後的真心評價（包含超美味推薦以及溫馨的小避雷心得）。

一目了然的精緻介面：首頁採用溫馨的暖色調與乾淨的卡片排版，並搭配我的實拍照片。

點擊查看詳細資訊：只要點擊任何一個有興趣的店家卡片，就會彈出詳細視窗，告訴你：

📍 精準的店家地址

🕒 營業時間（含公休日或售完為止的小提醒）

💬 我的走心真實心得與推薦必點品項

🥟 目前收錄的經典美食

第三市場肉粥 - 雞捲：清爽暖胃的肉粥配上酥脆炸物。

一品豆漿 - 起司抓餅：外酥內軟、老闆用心製作的夢幻早點。

大仁鍋貼 - 鍋貼 & 酸辣湯：現煎超酥脆鍋貼與夠味的酸辣湯。

樹人夜市 - 烤魷魚：阿公阿嬤手工炭烤的獨門醬汁魷魚（每週三限定）。

有記得的話會繼續更新!!
